# Copilot Studio 에이전트 운영 문의 Q&A

| 항목 | 내용 |
|---|---|
| 제품 | Copilot Studio (Standard harness) · Power Platform 환경 |
| 분류 | 운영 문의 모음 |
| 날짜 | 2026-11 |

거버넌스 담당에게서 받은 에이전트 관련 문의와 답변을 정리했습니다.

| 질문 | 답변 요약 |
|---|---|
| Default 환경에서 공유를 제한할 때 **이 에이전트만 예외**로 둘 수 있나? | 예외 방법 없음 → **다른 환경으로 이관**해야 함 |
| 이관하면 기존 사용자 링크가 바뀌는데? | 새 환경에서 받은 앱 Manifest 파일의 **ID를 기존(Default) 값으로 바꾸고 버전을 더 높게** 설정 → 같은 앱으로 유지됨 |
| '안녕' 같은 인사에 "의도를 파악할 수 없습니다"가 나옴 | **인사말(Greeting) 토픽이 꺼져 있음** → 활성화 |
| 답변이 너무 느림 | 모델 변경, 지침 줄이기, 토픽 줄이기 외에는 방법 없음. 가상 데스크톱(VDI) 등 사용자 단말 지연 영향도 확인 → **런타임(하네스) 변경 검토 권장** |

!!! note "런타임 변경 검토 시"
    Standard → Microsoft Copilot harness 업그레이드는 과금 방식이 달라집니다. [업그레이드 문서](../implementation/copilot-harness-upgrade.md)의 과금 차이를 먼저 확인하세요.
