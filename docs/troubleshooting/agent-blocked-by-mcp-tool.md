# 관리센터에서 에이전트가 자동으로 '차단됨'으로 바뀜

| 항목 | 내용 |
|---|---|
| 제품 | Microsoft 365 관리센터 · Agents Toolkit 에이전트 · MCP |
| 분류 | 거버넌스 |
| 날짜 | 2026-11 |

## 증상

- Agents Toolkit으로 만든 에이전트 여러 개를 M365 관리센터에 업로드
- 그중 **특정 에이전트만 상태가 '차단됨'으로 변경**
- 누가 차단했는지 문의가 들어옴

## 조사

- 에이전트를 **직접 차단한 사람은 없었음**
- 차단된 에이전트만 **특정 MCP 도구를 사용**하고 있었음

## 원인

거버넌스 담당이 해당 **MCP 도구를 차단** → 그 도구를 쓰는 **에이전트도 자동으로 차단**되었습니다.

## 해결

- 차단 원인이 도구 차단임을 안내
- 해당 도구가 필요하면 도구 승인 요청, 필요 없으면 에이전트에서 도구를 제거 후 재업로드

## 재발 방지

!!! tip "교훈"
    도구를 차단하면 그 도구를 쓰는 에이전트에 영향이 갑니다. **도구 차단 전에 영향받는 에이전트를 먼저 확인하고 만든 사람에게 알리는 절차**가 필요합니다.

- [ ] 도구(MCP 서버·플러그인) 차단 절차에 '영향 에이전트 확인 → 소유자 통지' 단계 추가
- [ ] 에이전트 업로드 전 사용하는 도구의 승인 여부 확인
