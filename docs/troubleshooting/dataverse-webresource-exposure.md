# Dataverse 웹 리소스 외부 노출 — CA 대신 IP 방화벽

| 항목 | 내용 |
|---|---|
| 제품 | Dataverse · Copilot Studio |
| 분류 | 보안 / 네트워크 |
| 날짜 | 2026-11 |
| 영향 | Dataverse 지식을 참조하는 에이전트 전체 (모바일 포함) |

## 배경

내부 직원이 만든 웹 페이지가 **외부에서 누구나 접속 가능한 상태**로 발견되었고, 보안 담당이 Dataverse 도메인 자체를 조건부 액세스(CA)로 차단했습니다.

## 증상

- CA 적용 후 **Dataverse 지식을 참조하는 에이전트가 모바일에서 동작하지 않음**
- 처음에는 특정 OS만의 문제로 보고됐으나, 확인 결과 Android·iOS 모두 동일

## 원인

외부에 노출된 페이지는 Power Pages가 아니라, **솔루션에 올린 정적 HTML 웹 리소스가 Dataverse 도메인에서 그대로 호스팅된 것**이었습니다. 이를 막으려고 도메인 전체에 CA를 걸면서 같은 도메인을 쓰는 에이전트 경로까지 막혔습니다.

## 해결

1. 도메인 단위 CA 대신 **Dataverse IP 방화벽(허용 IP만 접근)** 적용을 제안
2. 정적 HTML 웹 리소스 업로드 자체를 막는 방법 안내 (플러그인, 비즈니스 규칙 등)

목표는 **보안(외부 접근 차단)과 사용성(에이전트 계속 사용)을 함께 만족**하는 것입니다.

!!! warning "시험에서 확인된 한계"
    IP 방화벽 적용 후 Dataverse URL 직접 접근은 차단됐지만, **에이전트를 통한 Dataverse 지식 답변은 가능**했습니다. IP 방화벽만으로 에이전트 경로의 정보 노출까지 막는다고 볼 수 없습니다.

## 재발 방지

- [ ] 에이전트 **공유 범위**와 **지식 원본** 통제를 IP 방화벽과 함께 적용
- [ ] 정적 HTML 웹 리소스 업로드 정책 수립
- [ ] 도메인 단위 차단 전에 같은 도메인을 쓰는 서비스(에이전트, 모바일 앱) 영향 확인
